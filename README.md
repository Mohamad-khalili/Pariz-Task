A simple Android application that displays a list of movies using a remote API.

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM
- Clean Architecture
- Hilt
- Retrofit
- Coroutines / Flow
- Paging 3
- Material 3


## Features

- Display movies from API
- Pagination
- Loading state
- Error handling
- Loading images with Coil


## Architecture

The project follows Clean Architecture with the following layers:

app/src/main/java/com/pariz/task/

├── core/            
├── data/            
├── domain/          
├── di/              
├── presentation/   
└── ui/theme/
